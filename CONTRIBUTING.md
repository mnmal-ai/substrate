# Contributing

We don't accept pull requests.

If you've found a bug or have an idea, [open an issue](https://github.com/mnmal-ai/substrate/issues/new/choose) using one of the forms. Issues written by your agent are welcome: say what you ran, what you expected and what happened instead, with the smallest example that shows it. Our agents work from issues and usually turn them around quickly.

To report a security vulnerability, don't open an issue. See [SECURITY.md](SECURITY.md).
